How we protect your data · Last updated: 2026-05-09

1. הגרסה הקצרה

WizeLife handles sensitive data — financial, medical, tax. We follow modern, defense-in-depth practices: encrypted transport, encrypted storage, isolated user permissions, audited cloud providers, and a documented incident-response plan. We are a small team — we אנחנו לא claim enterprise-grade certifications yet, but we apply the same engineering principles.

2. הצפנה

  • בתעבורה: כל התעבורה ב-HTTPS/TLS 1.2+. HSTS preload, ללא תוכן מעורב.
  • במנוחה: Firestore encrypts all data with Google-managed keys (AES-256). Render and Vercel encrypt their volumes. Browser localStorage is not encrypted by us — that's handled by the device's OS-level security.
  • סודות: מפתחות API מאוחסנים רק ב-Render / Vercel / GitHub secret stores מוצפנים. לעולם לא ב-git, לעולם לא ב-logs.

3. אימות ובקרת גישה

  • אימות אימייל/סיסמא דרך Firebase Authentication. סיסמאות מוצפנות באלגוריתמי תקן תעשייתי (Firebase משתמש ב-scrypt + per-user salt).
  • כניסה דרך Google עם OAuth 2.0.
  • אסימוני סשן הם JWT (Firebase ID tokens), קצרי-טווח, מתחדשים אוטומטית.
  • כללי אבטחה של Firestore אוכפים: כל משתמש יכול לקרוא/לכתוב רק את המסמכים שלו. נבדק רציפות בבדיקות אוטומטיות.
  • Backend APIs require Authorization: Bearer <Firebase ID token>. גישה אנונימית מוגבלת בקצב לפי IP.

4. רשת ופרימטר

  • Cloudflare in front of wizelife.ai and tax.wizelife.ai: הקלת DDoS, WAF (חומת אש לאפליקציות), זיהוי בוטים.
  • כותרות אבטחה (HSTS, X-Frame-Options DENY, X-Content-Type-Options nosniff, strict CSP) on all pages — verified daily by our QA workflow.
  • הגבלת קצב בכל endpoints של ה-AI ב-backend (slowapi ל-FastAPI, middleware מותאם ל-Express).
  • CORS tightly scoped — only known WizeLife origins can call our APIs.

5. צמצום נתונים

אנחנו אוספים רק את הדרוש לכל כלי לעבוד. אנחנו לעולם לא אוספים:

  • Government IDs, passport numbers (free text only — not stored as IDs)
  • מספרי כרטיסי אשראי (Stripe מטפל ישירות כשהחיוב פעיל)
  • נתונים ביומטריים
  • מיקום גיאוגרפי מעבר לרמת מדינה
  • טביעות אצבע דפדפן או מזהי מכשירים למעקב

נתוני בריאות ונתונים פיננסיים רגישים מאוחסנים ב-localStorage של הדפדפן כברירת מחדל ומסונכרנים ל-Firestore רק אם אתה במפורש opt in.

6. עיבוד AI

כשאתה שואל את ה-AI שלנו:

  • השאלה שלך + הקשר הפרופיל המובנה נשלחים ב-HTTPS ל-Google Gemini.
  • למחקר בזמן אמת, שאילתה נגזרת נשלחת ל-Tavily.
  • ה-API בתשלום של Google Gemini אינו משתמש בפניות לקוחות לאימון מודלים.
  • אנחנו לא שומרים יומני שיחות AI לאחר הסשן, מעבר למה שאתה שומר במפורש בפרופיל שלך.

Full architecture: ARCHITECTURE.md (public).

7. ניטור רציף

  • תהליך QA יומי (GitHub Actions, 06:00 UTC) — runs 13 tiers of checks against every deployed page: HTTP status, console errors, broken assets, security headers, SSL expiry, accessibility (axe-core), SEO meta tags, PWA validity, multi-viewport, cross-app SSO, i18n, third-party APIs, cold-start latency, end-to-end auth flow.
  • ניטור uptime בזמן אמת via UptimeRobot — every endpoint pinged every 5 minutes. Owner alerted within 5 minutes of an outage.
  • צופה חוקי מס (שבועית) סורק שינויי רגולציה שמשפיעים על משתמשים.
  • Service Worker מתעדכן אוטומטית across all apps — every 5 minutes, the browser checks for new code and offers a one-click upgrade.

8. תגובה לתקריות

אם מתרחשת פריצת מידע:

  1. משתמשים מושפעים מקבלים הודעה במייל תוך 72 שעות (לפי חוק הגנת הפרטיות הישראלי ו-GDPR סעיף 33).
  2. הרשות להגנת הפרטיות הישראלית מקבלת הודעה, אם נדרש לפי חומרת ההפרה.
  3. דוח post-mortem מתפרסם בעמוד זה.
  4. אישורי גישה שנפגעו מוחלפים בכפייה.

10. דיווח על חולשה

אם גילית בעיית אבטחה, נא לשלוח מייל ל security@wizelife.ai עם פרטים וצעדים לשחזור. אנחנו עונים תוך 48 שעות.

נא:

  • Do תעשה לחשוף בפומבי לפני שהייתה לנו הזדמנות לתקן.
  • Do תעשה לגשת, לשנות, או למחוק נתונים של משתמשים אחרים.
  • Do תעשה להריץ סריקות אוטומטיות שפוגעות בשירות.

כרגע אין לנו תוכנית bug-bounty בתשלום, אבל נודה פומבית למדווחים אחראיים בסעיף זה.

11. מגבלות והערות גלויות

Things we אנחנו לא have yet — and you should know:

  • No SOC 2 / ISO 27001 audit (small team — those audits cost ₪50-100K). We'll pursue them when enterprise customers require it.
  • אין pen-test של צד שלישי בתיק (מתוכנן לפני אבן הדרך של 1,000 משתמשים).
  • No DPO (Data Protection Officer) — owner acts as primary contact for privacy matters.
  • No HIPAA covered-entity status — WizeHealth is for personal information, not for clinical use.
